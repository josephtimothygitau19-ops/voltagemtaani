# Voltage Mtaani AI Customer Agent ⚡

A GitHub-ready starter build for the Voltage Mtaani customer-agent concept.

## Included
- Customer enquiry simulator
- Lead extraction demo
- Emergency safety flagging
- Preliminary KSh quotation logic
- Lead approval hub
- Local browser persistence with `localStorage`
- Responsive dashboard UI

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Production upgrade
The original uploaded project contains the full React + Express + Gemini implementation. For production, connect the customer chat to the server API, keep `GEMINI_API_KEY` server-side, and connect persistent leads to a database/CRM before exposing the agent publicly.

## Repository
This build is on branch `build/voltage-mtaani-ai-agent` and is intended to be reviewed before merging to `main`.
